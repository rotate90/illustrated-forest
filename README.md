# Иллюстрированный лес

Интерактивная 3D-сцена на Three.js: лес, нарисованный так, будто это
старинная иллюстрация тушью и акварелью. Все текстуры создаются программно
через Canvas 2D API — в проекте нет ни одной скачанной картинки, модели или
стороннего графического ассета.

Сцены можно открыть просто двойным щелчком по `index.html`: сборщик, npm,
Node.js и локальный сервер не нужны.

---

## Как запустить

1. Скачайте папку проекта целиком (структура каталогов должна сохраниться).
2. Откройте `index.html` двойным щелчком — он откроется в браузере по адресу
   `file:///.../illustrated-forest/index.html`.
3. Дождитесь, пока нарисуются текстуры (несколько секунд: они генерируются
   программно при запуске). На экране видна полоса загрузки с подписями.
4. Кликните по сцене — курсор захватывается, и можно идти.

**Нужно подключение к интернету** — только для загрузки библиотеки Three.js
с CDN. Больше ничего извне не загружается. Если библиотека не загрузилась,
страница покажет понятное сообщение об ошибке с подсказкой, а не пустой экран.

### Если браузер не открывает проект через `file://`

Некоторые конфигурации браузеров (например, с жёсткой политикой безопасности)
запрещают запуск скриптов со страницы `file://`. В этом случае можно поднять
любой статический локальный сервер — **устанавливать пакеты проекта не нужно**,
достаточно штатных средств системы:

```bash
# Python 3 (обычно уже установлен)
python -m http.server 8000

# или Node.js, если он есть в системе
npx --yes serve .
```

Затем откройте `http://localhost:8000/` — путь должен указывать на каталог,
в котором лежит `index.html`.

## Управление

| Клавиши / действие | Что происходит |
| --- | --- |
| `W`, `A`, `S`, `D` | идти вперёд, влево, назад, вправо |
| Стрелки | то же, что `WASD` |
| Мышь | поворот камеры (в пределах ±84° по вертикали) |
| `Shift` | ускорить шаг вдвое |
| `Esc` | освободить курсор |
| Клик по сцене | снова захватить курсор |

Курсор захватывается через **Pointer Lock API**. Пока курсор не захвачен,
игра считается «на паузе»: клавиши движения сбрасываются, а на экране видна
подсказка. Коллизий, физики и взаимодействия с предметами нет — сквозь
растительность можно проходить свободно. Движение учитывает `delta time`,
поэтому скорость не зависит от частоты кадров, а диагональный шаг
нормализован.

### Порядок зависимостей

Скрипты подключаются как обычные `<script src="...">` в строгом порядке,
`async` не используется:

1. Three.js с CDN (и резервный CDN, если первый недоступен);
2. `src/config.js` — параметры, от которых зависят все модули;
3. `src/core/random.js` — генератор случайных чисел;
4. модули текстур: `textureFactory` → `treeTextures` → `foliageTextures` → `groundTextures`;
5. общие модули: `core/materials.js`, `core/instancing.js`;
6. модули окружения: `world/ground.js` → `world/stream.js` → `world/grass.js` →
   `world/ferns.js` → `world/branches.js` → `world/trees.js` → `world/foliage.js` →
   `world/birds.js` → `world/background.js`;
7. камера и управление: `core/camera.js`, `controls/firstPersonControls.js`;
8. сцена, рендеринг, композиция: `core/scene.js`, `core/renderer.js`, `world/forest.js`;
9. `src/main.js` — последним.

**Порядок обязателен, а не косметичен.** Каждый файл только *дополняет* общее
пространство имён `ForestApp` (`ForestApp.Config`, `ForestApp.Textures.Trees`,
`ForestApp.World.Trees` и так далее) и ничего не выполняет при загрузке, кроме
объявления функций и захвата ссылок на уже загруженные модули. Например,
`world/trees.js` в начале файла берёт `ForestApp.World.Terrain` и
`ForestApp.Instancing`, а `textures/treeTextures.js` — `ForestApp.Textures.Factory`.
Поэтому `ground.js` (в нём живёт `Terrain`) идёт раньше остальных модулей мира,
а `textureFactory.js` — раньше модулей текстур. Такой захват ссылок — осознанное
решение: он убирает ветвления в горячем пути размещения объектов.

Сборка мира идёт по явному плану в `world/forest.js`:

```
фон → земля → ручей → деревья → листва → ветки → папоротники → трава → птицы
```

Деревья строятся раньше листвы: `trees.js` возвращает список деревьев с
готовыми точками кроны и веток, а `foliage.js`, `branches.js` и `ferns.js`
получают этот список параметром. От порядка вызова этих трёх модулей результат
не зависит: каждое дерево уже описано данными.

## Основные настройки в `src/config.js`

| Параметр | За что отвечает |
| --- | --- |
| `seeds.*` | зёрна генератора. Композиция воспроизводима: два запуска дают одинаковый лес |
| `world.groundSize`, `world.groundSegments` | размер полотна земли и подробность рельефа |
| `world.dressingRadius` | радиус, в котором расставлена вся растительность |
| `world.playRadius`, `world.boundary` | зона прогулки и мягкая граница мира |
| `world.start` | точка появления и начальное направление взгляда |
| `world.eyeHeight` | высота камеры над землёй (1.62 м) |
| `stream.*` | линия ручья, ширина русла, уровень воды, глубина, скорость течения (`current`) |
| `fog.*` | цвет, начало и конец тумана (воздушная перспектива) |
| `camera.*` | угол обзора, ближняя и дальняя плоскости, предел наклона |
| `controls.*` | скорость шага, ускорение, чувствительность мыши |
| `render.*` | сглаживание, ограничение pixel ratio, пороги `alphaTest`, слой бумаги |
| `quality.density` | одним числом разрежает или сгущает всю растительность |
| `quality.textureScale` | множитель разрешения процедурных текстур |
| `quality.maxAnisotropy` | предел анизотропной фильтрации; применяется меньшая из поддержанных видеокартой |
| `counts.*` | количество деревьев, кустов, травинок, пятен и птиц |
| `palette.*` | палитра: тушь, бумага, небо, листва, трава, земля, кора, вода |

Примеры:

```js
// Сделать лес реже и легче для слабой видеокарты
quality: { density: 0.55, textureScale: 0.6, maxAnisotropy: 4 }

// Сделать туман дальше, чтобы лес читался резче
fog: { near: 40, far: 320 }

// Изменить палитру листвы
palette: { leaf: ['#c9d472', '#b6c65e', ...] }
```

## Как устроена графика

* **Плоские билборды.** Стволы — вертикальные плоскости (у ближних деревьев
  две-три, перекрещенные), кроны, кусты, трава и папоротники — также
  перекрещенные плоскости, которые **не** доворачиваются к камере каждый кадр.
  Деревья остаются вертикальными в мире: при движении возникает настоящее
  смещение ближних объектов относительно дальних.
* **Программные текстуры.** Каждая текстура рисуется один раз при запуске:
  заливка близкими оттенками, неровный контур тушью в два прохода, прожилки,
  штрихи, крапины и фактура старой бумаги. Затем текстуры переиспользуются.
* **Акварельные заливки.** Тон набирается радиальными градиентами, поэтому
  заливка «плывёт», как краска по бумаге, и не выглядит плоским цветом.
* **Вырезание по альфе.** Растительность использует `alphaTest` с
  `transparent: false`: силуэты попадают в непрозрачную очередь, пишут глубину
  и не требуют сортировки. Прозрачность `transparent: true` оставлена только
  там, где без неё не обойтись: вода ручья, тёмные заводи на её поверхности
  и верхний слой бумаги поверх кадра.
* **Течение без шейдеров.** Вода — два слоя одной и той же ленты: акварельная
  заливка и прозрачная плёнка ряби над ней. Оба слоя прокручиваются вдоль русла
  с разной скоростью (рябь примерно вдвое быстрее), плёнка ряби дополнительно
  чуть покачивается поперёк русла и «дышит» прозрачностью. В кадре меняются
  только смещения текстур, матрица одной группы и одно число прозрачности —
  геометрия и материалы не пересоздаются. Цена: один дополнительный вызов
  отрисовки и несколько обновлений юниформ.
* **Плоский свет.** Растительность, земля и вода рисуются
  `MeshBasicMaterial`: цвет берётся прямо из текстуры, а объём задаётся
  запечённой светотенью и перекрытием слоёв. Единственный материал, который
  получает свет от источников, — поваленные стволы (`MeshLambertMaterial`):
  у них видно и бок, и верх, поэтому им полезно живое освещение. Пни, ветки
  и вся остальная растительность остаются плоскими.
* **Пакетная отрисовка.** Однотипные элементы собраны в `InstancedMesh`
  (`src/core/instancing.js`), поэтому вся сцена укладывается примерно в
  70 вызовов отрисовки при десятках тысяч элементов.

## Производительность

* Текстуры, материалы и геометрии создаются один раз и переиспользуются.
* В кадре не создаются новые объекты: временные векторы и матрицы общие.
* Тени, отражения, постобработка и сложные шейдеры не используются.
* Качество регулируется через `quality` и `render` в `config.js`
  (`density`, `textureScale`, `maxAnisotropy`, `maxPixelRatio`, `antialias`,
  `paperOverlay`).
* Изменение размера окна и аспект камеры обрабатываются в `core/renderer.js`.
* Анимированы только вода и стаи птиц. Вода двигается смещением двух текстур
  и матрицы одной группы, птицы — движение целой группы и переключение двух
  поз крыльев. Ни один кадр не создаёт объекты и не трогает геометрию.
